# Crackdown event codebook

To be written in full before any events are coded (Weeks 3 to 4).

One row per discrete repressive act in `crackdowns.csv`. Fields: event_id, date
(IST), type, location, scale, anticipated, protest_scheduled, source_urls
(at least two independent outlets), coder, coded_at.

Allowed `type` values: mass_detention, leader_detention, house_arrest,
internet_shutdown, transit_closure, press_restriction, force_used.
